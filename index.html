Початок роботи

1. Підключіть смартфон до Wi-Fi мережі ESP32. 2. Відкрийте «З'єднання» та введіть адресу шлюзу. 3. Для першого запуску використовуйте лише пасивне прослуховування CAN.

Безпека

Активні команди вимкнені. Відображення «OK» у DEMO не є результатом діагностики реального автомобіля. Для реальної роботи потрібні перевірена електросхема, CAN-інтерфейс, прошивка та підтверджені протоколи ECU.

Активні перевірки компонентів

Двері водія → ручкаНЕАКТИВНО

Команди «висунути», «сховати» та «увімкнути підсвітку» передбачені в інтерфейсі, але навмисно заблоковані. Їх можна активувати лише після підтвердження адрес ECU, команд, зворотного зв'язку й умов безпеки.

Майбутній алгоритм

Команда → підтвердження ECU → контроль положення / струму / напруги → результат тесту → пояснення можливої несправності. При втраті зв'язку жодна команда не повинна залишатися активною.

Підключення до ESP32

Очікуваний протокол: WebSocket з JSON-кадрами {"type":"can","id":291,"data":[1,2],"ts_us":123456,"extended":false}. Це контракт для майбутньої прошивки ESP32, не готова підтримка заводського ПЗ Waveshare. На HTTPS-сайті потрібне з’єднання wss:// через захищений шлюз; прямий ws://192.168.4.1 заблокований браузером.
