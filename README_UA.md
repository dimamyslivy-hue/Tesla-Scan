# Tesla Network Scanner — Cloud v0.5

## Опублікувати через GitHub Pages

1. Створіть новий публічний репозиторій на GitHub, наприклад `tesla-network-scanner`. Не додавайте токени, VIN, CAN-логи або персональні дані.
2. Завантажте **вміст цієї папки**, включно з прихованими `.github/workflows/pages.yml` і `.nojekyll`, у корінь репозиторію (branch `main`). Найзручніше — GitHub Desktop або git.
3. У репозиторії відкрийте Settings → Pages → Build and deployment → Source → **GitHub Actions**.
4. Перевірте вкладку Actions → `Publish Tesla Scanner to GitHub Pages`. Після успішної публікації адреса буде `https://ВАШ-ЛОГІН.github.io/tesla-network-scanner/` (назва залежить від репозиторію).
5. Створіть ярлик Chrome на цю адресу.
6. Для наступного оновлення замініть файли у репозиторії та зробіть commit/push. Після успішного Actions deployment натисніть Ctrl+F5 (або F5, якщо кеш уже оновився).

## Важливі обмеження

- Це статичний демонстраційний інтерфейс; реального підключення до CAN поки немає.
- На HTTPS-сайті браузер забороняє незахищений `ws://` до ESP32. Для реальних даних потрібен окремий захищений WSS-шлюз із авторизацією, або локальний застосунок.
- Зміни в ChatGPT НЕ публікуються автоматично. Потрібен commit/push або підключений сервіс деплою.
- Налаштування localStorage прив'язані до адреси: налаштування старої локальної версії не переносяться автоматично на новий домен.
- Не публікуйте секрети, автомобільні логи, приватні дані у публічному репозиторії.
- У версії v0.5 змінено лише підготовку до хостингу та повідомлення про обмеження WSS.
